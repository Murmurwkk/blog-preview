磁力计标定的可辨识性：椭球拟合、坐标轴对准与绝对航向

把校准后的磁场向量整体旋转，模长仍相同，指向却会改变。椭球拟合可以估计中心和形状，确定航向还需要独立的方向参考。另用 256 对同时间戳的手机读数，可以把一次磁场强度异常追溯到磁场值和偏置的列序。

把手机转向不同方向，原始磁力计读数通常会落在一个偏心椭球上。校正偏置和各轴的伸缩后，点云可以重新落到球面，但要据此确定手机朝向，还需要知道球面上的向量怎样对应到设备坐标轴。

例如，让所有校正后的向量绕竖直轴旋转 90°，每个向量的模长、到球面的距离和拟合损失都保持原值。只要原来的水平投影非零，它的水平指向就转过了 90°。我们先用这个例子说明模长校准留下的旋转自由度，再看只做平面运动时还会缺少哪些约束。同一份手机日志里还有两种磁力计记录。逐条对齐时间戳后，可以看出另一类误差如何从读错字段顺序产生。

磁场模长、坐标轴对准与绝对航向

令 RWDR_{WD}RWD​ 把设备系向量转到世界系。一个便于讨论的模型是

y=ARWDTmW(p,t)+b+ϵ.y=A R_{WD}^{T}m_W(p,t)+b+\epsilon.y=ARWDT​mW​(p,t)+b+ϵ.

mWm_WmW​ 是位置和时间相关的世界系磁场，bbb 是加性偏置，AAA 合并了尺度、非正交、线性畸变与轴关系。这个模型只在有效范围内近似：设备状态变化、附件移动或环境变化，都可能让固定的 A,bA,bA,b 不再适用。

因此，用同一批读数做标定之前，最好先问清后来要拿结果做什么。下面三种目标从校正模长到确定世界航向，各需要多一层参考。

先校正幅度与形状。 在场强固定的条件下，如果偏置和方向相关的伸缩校正得当，传感器向各个方向转动时，读数应落在接近球面的点集上。

传感器与设备轴对齐。要把磁场与惯性数据结合起来，还需确定校正后的向量怎样变换到陀螺仪和加速度计使用的设备坐标系。

设备相对世界的方向。即使轴已经对齐，估计航向时仍需指定水平参考，因为磁北、地理北和室内地图的 x 轴可能指向不同方向。

第一项做得好，不等于后两项也解决了。反过来，某个固定安装下已知轴对齐，也不能保证换到另一块有磁扰动的环境里还能沿用同一套场模型。

磁场模长对椭球二次型的约束

先假设局部场恒定，模长归一为 1。写成 y=Au+by=Au+by=Au+b，其中 ∥u∥=1\|u\|=1∥u∥=1、AAA 可逆：

(y−b)TH(y−b)=1,H=A−TA−1.(y-b)^T H(y-b)=1, \qquad H=A^{-T}A^{-1}.(y−b)TH(y−b)=1,H=A−TA−1.

拟合椭球能估出中心 bbb 和对称正定矩阵 HHH。取一个 CCC 使 CTC=HC^TC=HCTC=H，对任何旋转矩阵 QQQ：

∥QC(y−b)∥2=(y−b)TCTQTQC(y−b)=(y−b)TH(y−b).\|QC(y-b)\|^2 =(y-b)^TC^TQ^TQC(y-b) =(y-b)^TH(y-b).∥QC(y−b)∥2=(y−b)TCTQTQC(y−b)=(y−b)TH(y−b).

由此可见，CCC 和 QCQCQC 对任意模长观测都给出相同解释。即使把行列式限定为正，排除镜像，三维旋转仍然不可辨识。取对称正定平方根 C=H1/2C=H^{1/2}C=H1/2 可以唯一确定一组计算用的坐标，却无法仅凭这一约定还原传感器的物理轴向。

极分解把这个现象写得更直白：对保手性的 AAA，设 A=SUA=SUA=SU，SSS 对称正定、UUU 为旋转，则 H=S−2H=S^{-2}H=S−2。对称白化给出 C=S−1C=S^{-1}C=S−1，于是

C(y−b)=S−1SUu=Uu.C(y-b)=S^{-1}SUu=Uu.C(y−b)=S−1SUu=Uu.

白化消除了伸缩，却把未知旋转 UUU 完整地保留了下来。因此，球面残差即使已经接近零，校正后的向量仍可能始终朝向一个偏转的方向。

如果真实场强也未知，将椭球归一化到单位球还会丢失以 µT 表示的绝对尺度。用于室内行走数据时，还需检查沿途场强是否近似恒定；若场强本来随位置变化，拟合就可能把环境变化吸收到 AAA 中，导致校准矩阵随采样路线而变。

平面激励下的秩不足

另一个构造对照点数还是 1000，但让所有真实向量都落在同一个水平圆上，再施加相同的 A,bA,bA,b。对居中后的九列设计矩阵做 SVD，全球面输入的数值秩是 9，平面输入是 5。平面输入那组的第六个奇异值只有约 5.13×10−155.13\times10^{-15}5.13×10−15，跟最大奇异值 65.42 比，已经在浮点误差量级。

两组对照都使用 1000 个点，可见秩的差异来自运动覆盖的方向。即使在同一平面继续采样，也无法约束缺失的三维方向。噪声会把零奇异值变成很小的正数，正则化也能使逆运算在数值上可做，但后者添加的约束来自先验，不能计作新观测的信息。

惯性观测对传感器轴向对准的约束

Kok 与 Schön 的《Magnetometer calibration using inertial sensors》发表于 IEEE Sensors Journal，2016，16(14):5679–5689。它把惯性数据用于轴对齐和离线最大似然校准，椭球拟合只是初始化。实验要求缓慢旋转，用直角块的相对 90° 转动验证，不能当作绝对地理航向真值。论文 v3 与实验章节

单位球残差只能检验校准后的形状。要检验轴对齐，需要与惯性参考相容的运动约束；如果还要评估设备的绝对朝向，则须引入独立的方向参考。用同一批磁力计数据训练和检查时，再小的球面残差也不能代替这种参考。

本文借用这篇论文来说明惯性约束能补上哪些方向信息。前面的构造计算只验证椭球的旋转歧义，并未运行论文的最大似然标定程序或硬件实验。

绝对航向所需的水平参考

前面讲的是传感器校准里的旋转；就算 A,bA,bA,b 都已知，世界参考还有另一层歧义。对任意绕世界竖直轴的旋转 GGG，同时令

RWD′=GRWD,mW′=GmW,R'_{WD}=G R_{WD},\qquad m'_W=Gm_W,RWD′​=GRWD​,mW′​=GmW​,

作上述变换后，仍有 RWD′TmW′=RWDTmWR_{WD}'^{T}m'_W=R_{WD}^{T}m_WRWD′T​mW′​=RWDT​mW​。传感器看到的磁向量没有变化，重力方向也一样。换句话说，如果缺少已知的水平参考，观测只确定设备与磁场之间的相对方向，不能分别解出设备的绝对 yaw 和磁场在世界坐标中的水平朝向。

陀螺仪测得相对旋转，因此能够约束不同时刻的姿态变化，却无法仅靠积分确定地理北。可以约定某一磁场方向为世界 x 轴，但要把它用于建筑地图，还得知道两者之间的方向关系。同理，行走路径的切线也不能直接拿来作为设备航向真值，因为人沿直线走时仍可以横持或转动手机。

水平磁场与航向的局部 Fisher 信息

现在做一个更强的假设：当地磁向量已知，设备相对重力的倾斜姿态（roll/pitch）也已知，只剩小 yaw 扰动要估计，各轴观测噪声独立零均值高斯、方差同为 σ2\sigma^2σ2。令 eze_zez​ 为已表达在设备系中的竖直单位向量，预测的设备系磁向量为 uuu，局部雅可比是

Hψ=−ez×u,Iψ=HψT(σ2I)−1Hψ=∥uh∥2σ2.H_\psi=-e_z\times u, \qquad \mathcal I_\psi =H_\psi^T(\sigma^2I)^{-1}H_\psi =\frac{\|u_h\|^2}{\sigma^2}.Hψ​=−ez​×u,Iψ​=HψT​(σ2I)−1Hψ​=σ2∥uh​∥2​.

旋转约定会改变雅可比矩阵的符号，却不改变信息量。这里的 uhu_huh​ 是磁场水平分量：即使总场很强，只要它接近竖直，微小航向变化对读数的影响就很弱。当水平分量为零时，该模型提供的航向信息也恰好为零。

图 3 右侧取演示参数 σ=1\sigma=1σ=1 µT。水平分量为 5、20 µT 时，各自提供 25、400 rad⁻² 的信息量。在常规正则条件下，单样本局部无偏估计的 Cramér–Rao 方差下界为 1/Iψ1/\mathcal I_\psi1/Iψ​，换算成标准差下界约为 11.46°、2.86°。这些角度只描述给定磁场和倾角的条件模型。实际手机可能有偏，低信噪比下的圆周误差分布也未必接近局部近似，因而不能把数字套到两款手机上，更不能用它解开上一节未知世界磁场的歧义。

多帧如果共享校准误差或环境变化，信息量还不能简单乘样本数。相关误差得进联合协方差；这跟共同来源观测如何更新状态里是同一个问题。

短时运动中的姿态、磁场与角速度误差

短时间动态也能提供约束，代价是要同时建模环境变化。设去偏、轴对齐后的向量为 u=RTm(p,t)u=R^Tm(p,t)u=RTm(p,t)，时间导数是

u˙=−ωD×u+RT∇m p˙+RT∂m∂t.\dot u=-\omega_D\times u +R^T\nabla m\,\dot p +R^T\frac{\partial m}{\partial t}.u˙=−ωD​×u+RT∇mp˙​+RT∂t∂m​.

观测到的磁向量变化既可能来自设备转动，也可能来自设备经过磁场空间梯度，或当地场强随时间变化。因此在构造 r=u˙+ωgyro×ur=\dot u+\omega_{gyro}\times ur=u˙+ωgyro​×u 后，残差中除了陀螺偏置仍会包含这两种环境效应。除非另有观测约束当地磁场的稳定性，否则很难区分它们各自的贡献。

固定加性偏置在单独的差分里会抵消，但直接把未去偏的 y=u+by=u+by=u+b 代进整个残差，还会留下 ωgyro×b\omega_{gyro}\times bωgyro​×b。逐采样差分又会放大高频噪声。所以“用了差分”既免不了偏置和轴关系的检查，也不能把混合残差当成纯陀螺误差。

判断当地场是否相容时，校准可信、重力方向已知是两个前提。满足它们以后，可以比较模长、竖直投影和水平模长。然而这三项都不会随纯 yaw 旋转而变，所以它们能保留一个与数据相容的磁场假设，却不能单独找回 yaw 或排除其他成因。

因此，椭球拟合给出的是描述场强的二次型，惯性运动提供的是传感器坐标轴之间的约束，而绝对航向还需要已知的水平参考。设计校准实验时，应按目标分别选择对应的观测和评价指标。

若要把自然行走中的设备航向作为评价对象，还需要独立的方向参考，并说明它和建筑地图、地理北或磁北之间的关系，以及校准适用的时段和环境。若只有磁场地图，仍然可以在留出位置上评价场值预测或跨时段重复性，只是测到的指标要按相应任务解释。

椭球平移对常数项的影响

除了方向本来不可辨识，程序还可能把能够辨识的尺度算错。历史 T152 报告就记下了恢复椭球常数项时的一处错误。我们在这里用一个代数反例重新核对那个符号，未重跑报告中的 72 个日志。

在已经减去拟合原点的坐标 xxx 里，拟合式是

xTQx+2vTx=1,c=−Q−1v.x^TQx+2v^Tx=1, \qquad c=-Q^{-1}v.xTQx+2vTx=1,c=−Q−1v.

配方后应该是

(x−c)TQ(x−c)=1−vTc.(x-c)^TQ(x-c)=1-v^Tc.(x−c)TQ(x−c)=1−vTc.

式中的 ccc 使用拟合时的局部坐标，因此恢复到原始坐标的中心不能直接代入这个常数项。以 (x−1)2=4(x-1)^2=4(x−1)2=4 为例，写成 x2/3−2x/3=1x^2/3-2x/3=1x2/3−2x/3=1 后有 Q=1/3Q=1/3Q=1/3、v=−1/3v=-1/3v=−1/3、c=1c=1c=1。按上式计算，右侧为 4/34/34/3，正好恢复半径 2；若误写为 1+vTc1+v^Tc1+vTc，得到的半径便变为 2\sqrt{2}2​。

这个符号一错，恢复出的尺度就变了，哪怕二次型拟合本身没失败。拟合代码明确检查了秩、正定性、恢复中心和误差；它仍然只是无噪声反例的实现，不能拿来当自然数据稳健标定器的生产代码。

MAGU 的交错数据列与 MAGN 的匹配

为了把代码中的字段顺序和文件实际内容对上，我们从 IPIN 训练日志 Trial21 / session01 / SG24 提取了同一设备的两类磁力计记录，并在提取前核对原文件的完整 SHA-256。两种记录的表头给出了不同的列序。

MAGN;AppTimestamp;SensorTimestamp;Mag_X;Mag_Y;Mag_Z;Accuracy
MAGU;AppTimestamp;SensorTimestamp;Mag_X;bias_X;Mag_Y;bias_Y;Mag_Z;bias_Z;Accuracy

对分号切开的数组 p，并让 p[0] 保留记录类型，正确的读法是：

field = np.array([float(p[3]), float(p[5]), float(p[7])])
bias  = np.array([float(p[4]), float(p[6]), float(p[8])])
device_debiased = field - bias

这里尤其容易把 Android API 和落盘格式搞混。官方未校准磁力计接口把三轴场值和三轴偏置放在不同数组位置，而这个采集程序选了逐轴交错存储。文件读者必须遵守文件自己的表头。官方文档还说明，“未校准”不等于没做过任何处理：那个输出仍可能保留出厂校准和温度补偿；普通磁场输出通常近似于未校准场值减去估计偏置。Android：Position sensors

256 组同时间戳记录的逐轴核对

为了检查字段解释在连续记录中是否也成立，我们取原文件最前面的 256 条 MAGU，覆盖 AppTimestamp 0.024–5.114 s，再为每条记录查找 SensorTimestamp 完全相同的 MAGN。256 条全部得到精确匹配，因而这里无需插值、最近邻配对或移动时间轴。

每一对记录都能按时间精确对齐以后，我们将所有匹配点的三个磁场分量一并用于计算 RMSE。

两个时间戳各自能证明什么也得克制。原文件第 61780、61786 行的 SensorTimestamp 分别是 25950.082 和 25950.102 s，而场值与偏置的六个文本字段完全相同。这足以否掉“时间戳不同、数值就一定不同”；但光靠两行数据判断不了底层究竟是采样保持、量化还是稳定输入，也不能据此给整个日志定一条新的去重政策。把相同数值的独立采样全删掉，同样可能改动噪声统计。
