稀疏自编码器的特征恢复：已知字典上的重建误差与方向匹配

稀疏自编码器除了重建输入，还希望找出生成输入的特征方向。在已知字典上做的 36 次训练中，将 TopK 的激活上限放宽后，模型重建得更准，恢复的真实方向反而更少。原因是几条方向即使各有偏差，组合起来仍可能重建出同一输入，单看重建误差就分不出用了哪些方向。

如果生成数据所用的特征字典已知，我们就能分别检验稀疏自编码器的两项能力：它能否准确重建输入，以及它能否找回生成这些输入的方向。在下面的合成实验中，把每个输入允许激活的潜变量从两个增至四个，三个字典上的重建误差都降低了，找回的方向数中位数却都下降了。要理解这两个指标为何会分离，可以先看一个能用多种稀疏组合精确表示的输入。

两个非负特征在同一坐标中的叠加

要看一个坐标如何表示多个潜在特征，我们从两个非负特征 f1,f2f_1,f_2f1​,f2​ 出发，仅保存它们的差值：

h=f1−f2.h=f_1-f_2.h=f1​−f2​.

如果两个特征从不同时出现，解码器只需判断差的正负，就可以分别还原它们：

f^1=ReLU⁡(h),f^2=ReLU⁡(−h).\hat f_1=\operatorname{ReLU}(h),\qquad \hat f_2=\operatorname{ReLU}(-h).f^​1​=ReLU(h),f^​2​=ReLU(−h).

在这种输入分布下，差值的正负号足以区分两个特征，绝对值则给出强度。一个坐标就能恢复两个可能的特征，是因为允许出现的状态只落在两条非负坐标轴上，不用铺满整个平面。

一旦两个特征可能同时出现，相同的差值便可能来自不同输入。例如 (f1,f2)=(0.8,0.3)(f_1,f_2)=(0.8,0.3)(f1​,f2​)=(0.8,0.3) 和 (0.5,0)(0.5,0)(0.5,0) 都给 h=0.5h=0.5h=0.5，解码器只能还原成 (0.5,0)(0.5,0)(0.5,0)。两个特征同时为正，平方误差之和是 2min⁡(f1,f2)22\min(f_1,f_2)^22min(f1​,f2​)2。但如果每个特征独立地以概率 ppp 出现，两者同时出现的概率仅为 p2p^2p2。因此特征足够稀疏时，把它们存进一个坐标，虽然在少数输入上会混淆，平均重构误差仍可能低于始终舍弃其中一个特征。

《Toy Models of Superposition》把这个取舍做成了训练实验：输入是已知的稀疏特征，模型先压进低维空间再恢复，特征的重要性和出现频率会改变它把哪些方向叠在一起。superposition 说的就是可用特征数超过表示维度、几个特征靠非正交方向共用空间。

一维的正负方向推广到 ddd 维：

h=D∗f=∑j=1mdjfj,D∗∈Rd×m,m>d.h=D_*f=\sum_{j=1}^{m}d_jf_j,\qquad D_*\in\mathbb R^{d\times m},\quad m>d.h=D∗​f=j=1∑m​dj​fj​,D∗​∈Rd×m,m>d.

D∗D_*D∗​ 的每一列是一个方向，fjf_jfj​ 是那个方向的非负强度。单个神经元记下的是

hi=∑j(D∗)ijfj.h_i=\sum_j(D_*)_{ij}f_j.hi​=j∑​(D∗​)ij​fj​.

由此可见，多个特征在同一坐标上的投影都可能使一个神经元激活。只检查它最活跃的几个输入，很难据此判断神经元是否对应唯一语义。

这个简化模型只描述线性叠加。真实语言模型中的概念可能涉及多个维度，逐坐标的非线性也使得旋转坐标基可能改变计算结果。SAE 所检验的假设更具体：在选定的位置，少数激活方向的线性组合能否逼近观测到的激活。

即使把目标限定为稀疏重构，给定一个激活也可能有多个解。下面的二维例子说明了这种歧义。把五个单位方向均匀铺在圆上，相邻夹角 72°，就有

d0+d2=2cos⁡(72∘)d1≈0.618034d1.d_0+d_2=2\cos(72^\circ)d_1\approx0.618034d_1.d0​+d2​=2cos(72∘)d1​≈0.618034d1​.

红点既可写为两个方向的和，也可由一个带系数的方向单独表示。用 NumPy 比较这两种表示得到的坐标，最大差小于 10−1410^{-14}10−14。这些方向没有语言含义。

如果生成过程真用了 d0+d2d_0+d_2d0​+d2​，偏爱更少非零项的算法会挑另一种解释。想把歧义消掉一部分，只能多放样本进来，利用「哪些方向常单独出现、哪些组合很少出现」这类统计关系。数据里没有的区分，重建目标补不出来。

稀疏自编码器的特征检测方向与重构方向

实际训练时，可以从已经训练好的语言模型中采集许多激活 hhh，却无法直接观察上例中的生成字典 D∗D_*D∗​ 与系数 fff。稀疏自编码器需要同时学习解码字典 DDD 和从 hhh 估计系数的编码器：

u=Wenc(h−b)+benc,z=ReLU⁡(u),h^=Dz+b.u=W_{\mathrm{enc}}(h-b)+b_{\mathrm{enc}},\qquad z=\operatorname{ReLU}(u),\qquad \hat h=Dz+b.u=Wenc​(h−b)+benc​,z=ReLU(u),h^=Dz+b.

其中 h,h^,b∈Rdh,\hat h,b\in\mathbb R^dh,h^,b∈Rd，z∈Rmz\in\mathbb R^mz∈Rm，通常 m>dm>dm>d。解码器的每一列指定一个方向，相应潜变量的系数越大，这一方向对重构的贡献越大。编码器中对应的一行则用来判断哪些输入会使这个潜变量激活。

比如直接把字典转置当编码器：

D⊤h=D⊤D∗f.D^\top h=D^\top D_*f.D⊤h=D⊤D∗​f.

即使恰好学到 D=D∗D=D_*D=D∗​，只要字典方向之间不正交，其他特征在这一方向上的投影仍会改变检测结果。编码器可以用解码器的转置初始化，但训练期间是否继续让两者共享参数，是需要单独决定的约束。

普通 ReLU SAE 的目标写成

L=Eh[12∥h−h^∥22+λ∥z∥1].\mathcal L= \mathbb E_h\left[ \frac12\|h-\hat h\|_2^2+\lambda\|z\|_1 \right].L=Eh​[21​∥h−h^∥22​+λ∥z∥1​].

第一项衡量重构 Dz+bDz+bDz+b 与原激活之间的误差，第二项则惩罚编码系数的总幅度。去掉第二项后，只要字典足够宽，自编码器仅靠复制输入便能减小损失，目标函数也不再要求它分离经常一起出现的因素。加入稀疏约束后，模型要在重构准确的同时尽量减少使用的特征或压低系数幅度。

上述目标还存在一种缩放歧义：某列 djd_jdj​ 放大 ccc 倍、zjz_jzj​ 缩小 ccc 倍，重建不变，L1 却更小。实操里要约束解码列的范数，或者换成 ∑j∣zj∣∥dj∥2\sum_j|z_j|\|d_j\|_2∑j​∣zj​∣∥dj​∥2​ 这类对尺度不变的惩罚。下文实验每列都取单位范数。这固定了尺度，排列、重复方向和上一节的分解歧义都还在。

《Towards Monosemanticity》在单层 Transformer 的 512 维 MLP 激活上研究过这种字典，详细分析的那个版本有 4096 个潜变量。4096 比 512 大，多出来的是候选方向的数量，不是每次都要用的维数。字典多宽、一次开几项，得分开控制；否则误差降了，也说不清是因为选项更多，还是因为每个样本开了更多方向。

L1 惩罚对激活系数的收缩

固定其他方向的系数，先从输入中减去它们对重构的贡献，再将剩余向量投影到待求的单位方向上。设这个投影为正，记为 ttt，该方向的系数为 a≥0a\ge0a≥0。此时只需解一个标量 L1 子问题：

min⁡a≥012(t−a)2+λ1a⟹a∗=max⁡(t−λ1,0).\min_{a\ge0}\frac12(t-a)^2+\lambda_1a \quad\Longrightarrow\quad a^*=\max(t-\lambda_1,0).a≥0min​21​(t−a)2+λ1​a⟹a∗=max(t−λ1​,0).

因此 L1 不仅会将较小的系数压为零，较大的系数即使保留下来，也会统一减去 λ1\lambda_1λ1​。这是直接按非零系数的幅度施加惩罚的结果。

另一种做法是用 L0 只统计非零系数的个数。对单个方向而言，只要系数非零，就要支付相同的惩罚：

min⁡a≥012(t−a)2+λ01[a>0],\min_{a\ge0}\frac12(t-a)^2+\lambda_0\mathbf1[a>0],a≥0min​21​(t−a)2+λ0​1[a>0],

如果保留这一方向，系数取 ttt 就能消除重构误差。将系数设为零时，总损失为 t2/2t^2/2t2/2；将系数保留在最佳幅度时，总损失则为 λ0\lambda_0λ0​。比较二者就能决定是否保留。

等号成立时，两种选择给出的损失相同。这个单方向推导无法直接求出非正交字典的全部系数，但能说明，限制非零系数的数量与压小已激活系数的幅度是两个不同目标。

TopK 的激活数上限与 JumpReLU 的逐特征阈值

另一种限制稀疏度的办法是 TopK。它对每个样本挑选编码器预激活中最大的 kkk 项。Gao 等人的论文研究这类 SAE 的扩展规律，把重建、可解释性和下游作用分开考察。公开实现的核心是这几行：

topk = torch.topk(x, k=self.k, dim=-1)
values = self.postact_fn(topk.values)
result = torch.zeros_like(x)
result.scatter_(-1, topk.indices, values)
return result

这里的 xxx 是编码器预激活，不是语言模型的原激活。最后一维是字典里的全部潜变量，所以竞争发生在每个样本内部。代码来自 OpenAI sparse_autoencoder/model.py 的固定提交，MIT 许可，见 LICENSE。

要理解非零项为什么可能少于上限，还需注意实现先选最大值，再应用默认的 ReLU。将 [−5,−3,−1,−7][-5,-3,-1,-7][−5,−3,−1,−7] 作为实际实现的输入，取 k=2k=2k=2，被选中的负值仍会变为零。所以 TopK 保证的是至多 kkk 个非零。选中的预激活不再统一减一个 L1 阈值，但它们仍是编码器的估计值，不等于真实特征强度。

TopK 的门槛跟着样本走：某个方向的预激活没变，只要同一样本里别的方向更强，它就可能掉出前 kkk。如此可以设定每个样本的计算或存储上限。不过，简单输入与包含多个特征的复杂输入具有相同上限，未必匹配实际需要。

JumpReLU 则为每个特征方向分别学习一个阈值：

zj=uj1[uj>θj],L=∥h−h^∥22+λ∥z∥0.z_j=u_j\mathbf1[u_j>\theta_j],\qquad \mathcal L=\|h-\hat h\|_2^2+\lambda\|z\|_0.zj​=uj​1[uj​>θj​],L=∥h−h^∥22​+λ∥z∥0​.

当预激活超过相应阈值时保留原幅度，否则输出为零。因此不同输入可以激活不同数量的方向，阈值 θj\theta_jθj​ 由训练确定。难点在于，对固定样本，只要阈值没跨过 uju_juj​，输出就不变，普通自动微分几乎处处给不出阈值的梯度。

不变的是单个样本的输出，输入分布上的平均损失未必不变。回到刚才那个标量问题，令 t∼U[0,2]t\sim U[0,2]t∼U[0,2]、输出 a=t1[t>θ]a=t\mathbf1[t>\theta]a=t1[t>θ]。在 0≤θ≤20\le\theta\le20≤θ≤2 内，被关掉那部分的损失是积分 ∫0θ(t2/2)(1/2) dt\int_0^\theta(t^2/2)(1/2)\,dt∫0θ​(t2/2)(1/2)dt，被开启的概率是 1−θ/21-\theta/21−θ/2。于是

EL(θ)=θ312+λ0(1−θ2),dELdθ=θ24−λ02.\mathbb E\mathcal L(\theta) =\frac{\theta^3}{12}+\lambda_0\left(1-\frac\theta2\right), \qquad \frac{d\mathbb E\mathcal L}{d\theta} =\frac{\theta^2}{4}-\frac{\lambda_0}{2}.EL(θ)=12θ3​+λ0​(1−2θ​),dθdEL​=4θ2​−2λ0​​.

平均损失有明确的最低点 θ=2λ0\theta=\sqrt{2\lambda_0}θ=2λ0​​，代入图中的参数即为 0.5。当阈值略微移动时，原先位于阈值附近的一部分样本会从保留变为舍弃，或从舍弃变为保留。正是这些样本在输入分布中占据的概率，使平均损失对阈值的导数可以非零。

JumpReLU 论文用阈值附近的核密度估计构造直通梯度。阈值伪导数里有

∂~ JumpReLU⁡θ(u)∂θ=−θεK ⁣(u−θε).\frac{\widetilde\partial\,\operatorname{JumpReLU}_\theta(u)} {\partial\theta} =-\frac{\theta}{\varepsilon} K\!\left(\frac{u-\theta}{\varepsilon}\right).∂θ∂JumpReLUθ​(u)​=−εθ​K(εu−θ​).

带宽 ε\varepsilonε 决定阈值附近多大范围内的样本参与梯度估计。增大带宽会引入更多样本，其中也包括离阈值较远的输入；缩小带宽能使估计更局部，却可能因样本不足而增加波动。上图展示了标量目标为何需要这样的梯度估计。下面的字典恢复实验则实际训练 TopK 模型。

TopK 配对实验：固定输入样本，改变初始化

要直接检验重构误差能否反映方向恢复，实验使用已知字典生成输入。具体做法是随机取 12 个八维单位方向，每条方向独立以概率 ppp 出现，强度在 [0,1][0,1][0,1] 均匀采样。p=0.08p=0.08p=0.08 和 0.320.320.32 时，平均每个输入含 0.96 和 3.84 条真实方向。每个字典的独立测试集有 8,192 个样本。学习字典的宽度固定为 24。

种子 918 对应探索阶段已经使用的生成字典。为检验结果是否只出现在这一本字典上，确认实验还预先抽取了种子 919、920 对应的两本字典。对同一字典和密度，用同一串小批输入独立改变初始化（0、1、2），并在每次初始化下配对比较 k=2,4k=2,4k=2,4。一共 3×2×3×2=363\times2\times3\times2=363×2×3×2=36 次训练。每轮用 Adam、学习率 0.003，走 2,400 步，每步 256 个样本，步末将解码列归一成单位向量。测试集不参与选 checkpoint。

对每次训练分别计算重构误差与已恢复的方向数。归一化均方误差（NMSE）把重建平方误差除以“永远预测测试均值”的误差。方向数先把学到的列和生成方向一对一匹配，再数余弦达到 0.9 的项，满分 12。这个方向匹配指标衡量几何方向的恢复情况，单个样本的系数与语义还需另外验证。

替换模型激活后的损失与因果检验

上面的实验依靠已知字典核对方向。在真实语言模型中没有 D∗D_*D∗​ 可以直接比较，因此第一项可做的检验是用重构 h^\hat hh^ 替换原激活 hhh，再比较下游输出或损失是否改变。

激活 MSE 回答不了这个问题。设下游只看 100h1100h_1100h1​，第一维差 0.01，输出就差 1；同样大小的误差落在第二维，什么也不改。语言模型还有多层非线性和最后的 token 概率，不能把每个方向的重建误差当成一样重要。SAE 论文因此会测替换后的下游损失，不只报一条重建曲线。

实际注入可以走激活 hook。TransformerLens 固定版本的 hook_points.py 里，HookPoint 自己只有：

def forward(self, x: Tensor) -> Tensor:
    return x

在前向钩子处注册函数后，函数可以读取并缓存此处的 hhh，也可以返回 h^\hat hh^ 替换原张量，让后续层处理重构结果。如果没有注册钩子，该位置就会直接传递原激活。该实现是 MIT 许可。

注入位置本身也算解释的一部分：MLP 非线性输出、Attention 输出、残差流，维数一样也是不同的计算对象。在一处学到的方向，不能因为 shape 对得上就搬到另一处用。

检验完整激活的重构之后，还可以只消除某个方向，考察它在同一计算中的作用。设

h=Dz+b+ϵ,h=Dz+b+\epsilon,h=Dz+b+ϵ,

ϵ\epsilonϵ 是 SAE 的重建残差。只消掉第 jjj 个潜变量，应该得到

h′=h−djzj=b+∑i≠jdizi+ϵ.h'=h-d_jz_j =b+\sum_{i\ne j}d_i z_i+\epsilon.h′=h−dj​zj​=b+i=j∑​di​zi​+ϵ.

上式保留了原始重构残差，因此下游的变化可以用于检验指定方向的贡献。若改为输入 b+∑i≠jdizib+\sum_{i\ne j}d_i z_ib+∑i=j​di​zi​，则目标方向和重构残差会同时被去掉，此后便无法区分两者分别对下游变化贡献了多少。

若要给一个方向赋予语义，可以先观察激活最高的样本，提出一个能解释共同主题的名称。接下来应换用没有参与命名的输入，寻找本该激活却没有激活、或者按解释不该激活却被激活的反例。最后再改变强度或移除该方向，检查下游输出是否按预期变化。干预幅度如果远超模型平常经历的范围，即便产生显著变化，也难以据此确认自然计算时采用了相同路径。

《Towards Monosemanticity》将样本解释与干预联系起来，还讨论了字典变宽时原有特征怎样分裂。TopK 的研究则分别评估重构、探针与下游消融，因为同一激活可能有多种稀疏表示。观察重构就能比较这些表示还原输入的能力，却无法据此判断其中哪个方向参与了模型的下游行为。

本次训练直接检验了已知字典上的方向恢复，没有加载真实语言模型做语义命名或消融。三个字典的结果表明，仅凭较低的重构误差无法判断模型是否恢复了生成方向。若要进一步把某个方向解释为语言模型中的概念，还需在未见输入上检验它的激活规律，并通过干预观察它对原计算的影响。
