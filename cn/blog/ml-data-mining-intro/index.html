机器学习与数据挖掘入门：核心模型族、优化原理与防泄漏评估

面向入门读者系统梳理经典机器学习与数据挖掘方法，依次介绍监督与无监督核心算法族、损失与优化权衡、特征预处理原则，以及避免数据泄漏的切分与评估指标。

在接触大型深度神经网络之前，结构化表格预测、异常检测、用户分群和传感器特征建模等大多数实际任务，主要依赖经典机器学习（Machine Learning）与数据挖掘（Data Mining）方法。理解这些基础模型各自做了什么假设、如何优化目标函数以及评估流程容易在哪里出错，不仅能直接解决大量工程问题，也能为后续学习深度学习打下扎实的统计学底座。这篇导读依次梳理数据挖掘的标准工作流、监督与无监督核心算法族（线性模型、近邻、支持向量机、决策树与集成学习、聚类、降维）、优化与偏差–方差权衡，以及防止数据泄漏的特征工程与评估纪律。

如需同时了解计算机系统底层与深度学习/大模型概念，可配合阅读计算机基础全景导读。文中用于直观演示的手工算例均标注“（计算值）”。

机器学习与数据挖掘的标准流程

数据挖掘强调从原始杂乱记录中提炼可靠模式与可落地预测的完整过程，机器学习则是其中负责从数据自动拟合统计模型的算法工具箱。一条严谨的数据挖掘流程通常按如下顺序推进：

flowchart LR
    R[原始数据与标签] --> C[清洗与探索性分析：<br/>缺失值 / 异常值 / 字段分布]
    C --> S[先划分数据集：<br/>训练 / 验证 / 测试]
    S --> F[特征工程：<br/>仅在训练集上拟合变换参数]
    F --> M[模型训练与交叉验证调参]
    M --> E[在独立测试集上用业务匹配指标验收]

从是否提供已知答案出发，机器学习主要分为两大类（此外还有通过与环境交互、依据奖惩信号学习策略的强化学习）：

  • 监督学习（Supervised Learning）：每条训练记录都包含特征 xxx 和已知目标 yyy。目标为连续数值（如房价、耗时、温度）时称回归（Regression）；目标为离散类别（如垃圾邮件识别、故障类型）时称分类（Classification）。
  • 无监督学习（Unsupervised Learning）：数据只有特征 xxx 而没有标签，目标是挖掘内在结构，包括把相似样本归类的聚类（Clustering）、压缩冗余特征的降维（Dimensionality Reduction）以及识别罕见模式的异常检测（Anomaly Detection）。

监督学习核心模型族

不同算法家族本质上带有不同的归纳偏置（Inductive Bias）——即对数据背后规律形状的先验假设。

线性模型与正则化

线性回归用特征的加权和 y^=w⊤x+b\hat{y} = w^\top x + by^​=w⊤x+b 拟合连续目标，通常最小化均方误差；逻辑回归（Logistic Regression）把同样的线性打分 z=w⊤x+bz = w^\top x + bz=w⊤x+b 送入 Sigmoid 函数 σ(z)=1/(1+e−z)\sigma(z) = 1 / (1 + e^{-z})σ(z)=1/(1+e−z) 映射到 (0,1)(0, 1)(0,1) 区间输出分类概率，通过最小化交叉熵损失求解。

当特征很多或彼此高度相关时，不受约束的权重很容易变得极大，去死记训练噪声。正则化在损失函数上追加权重大小惩罚项：

  • L2 正则化（岭回归 / Ridge）：加入 λ∑jwj2\lambda \sum_j w_j^2λ∑j​wj2​，把所有权重平滑压缩，显著缓解特征共线性带来的数值不稳定；
  • L1 正则化（Lasso）：加入 λ∑j∣wj∣\lambda \sum_j |w_j|λ∑j​∣wj​∣，倾向于把无关特征的权重精确压为 0，兼具自动特征选择效果。

基于距离与核的方法

kkk 近邻（kkk-NN）几乎不做显式参数训练：预测新样本时，直接按距离度量（如欧氏距离）找出训练集里最近的 kkk 个点，回归取均值、分类取多数表决。因为距离对数值尺度极度敏感，特征量纲差异很大时必须先做归一化。

支持向量机（SVM）寻找能最大化两类样本间隔（Margin）的决策边界，边界位置只由离边界最近的一小批“支持向量”决定。当样本在原始空间线性不可分时，SVM 借助核技巧（Kernel Trick，如高斯 RBF 核）隐式计算高维特征空间中的内积，从而画出平滑的非线性分类边界。

决策树与集成学习

决策树（Decision Tree）通过递归地沿单个特征做阈值切分（例如 年龄 <= 30）把特征空间划成若干矩形区域，每次切分挑选能让子节点最“纯净”的特征与阈值。分类任务常用的纯度指标之一是基尼不纯度（Gini Index） G=1−∑cpc2G = 1 - \sum_c p_c^2G=1−∑c​pc2​。

以一个包含 4 个正样本和 4 个负样本的节点为例（p+=p−=0.5p_+ = p_- = 0.5p+​=p−​=0.5），当前基尼不纯度为 G=1−(0.52+0.52)=0.5G = 1 - (0.5^2 + 0.5^2) = 0.5G=1−(0.52+0.52)=0.5（计算值）。如果某个切分将其完美分成左子节点 (4 正, 0 负)（GL=0G_L = 0GL​=0）和右子节点 (0 正, 4 负)（GR=0G_R = 0GR​=0），纯度增益达到最大可能值 ΔG=0.5−0=0.5\Delta G = 0.5 - 0 = 0.5ΔG=0.5−0=0.5（计算值）。

单棵深树直观易解释、且不怕特征量纲不统一，但对数据扰动极度敏感，极易过拟合（高方差）。两类集成策略让树模型成了结构化表格数据上的绝对主力：

  • Bagging 与随机森林（Random Forest）：通过自助重采样生成多份训练子集，并在每个分裂节点随机抽取一部分特征，并行训练大量深树后取平均或投票。多棵树的随机误差相互抵消，显著降低方差。
  • 梯度提升树（GBDT，代表实现如 XGBoost / LightGBM）：串行训练一批浅树，每一棵新树专门拟合前面所有树留下的负梯度（残差），步步逼近真实规律，显著降低偏差。配合学习率、树深限制和子采样，GBDT 在绝大多数表格竞赛与工业场景中都是最强基线。

无监督学习与数据挖掘基础

在没有人工标注的情况下，无监督算法直接从特征分布中提取结构：

  • kkk-Means 聚类：交替执行“将每个样本分配到最近的质心”和“重新计算各簇的质心均值”，直到分配不再变化。算法简洁高效，但需要预先指定簇数 kkk，且隐含假设每个簇大致呈球形、大小相近。
  • DBSCAN（基于密度的聚类）：只要某点半径 ε\varepsilonε 内至少包含 minPts 个邻居就将其归为核心点并向外连通扩张。它无需预先指定簇数，能够发现任意弯曲形状的簇，同时把孤立低密度点自动标为噪声或异常点。
  • 主成分分析（PCA）：将高度相关的数值特征线性投影到一组彼此正交的新坐标轴（主成分）上，按保留方差从大到小排序。丢弃方差极小的后段成分既能去冗余、加快下游训练，也常用于高维数据的二维/三维可视化。

优化求解、损失函数与偏差–方差权衡

参数化模型的训练大多归结为最小化“经验损失 + 正则项”：

  • 一阶与二阶优化：梯度下降（及小批量 SGD、Adam）只计算一阶导数，每次迭代开销小，适合超大规模参数模型；对于中小规模的光滑目标（如非线性最小二乘），牛顿法、高斯–牛顿法与 L-BFGS 引入二阶曲率信息，往往几十步即可高精度收敛。
  • 损失函数选择：平方误差（ℓ2\ell_2ℓ2​）对应高斯噪声假设，对极大异常值极其敏感；绝对误差（ℓ1\ell_1ℓ1​）与 Huber 损失 在残差较大时按线性增长，能有效抵御脏数据干扰。
  • 偏差–方差权衡（Bias–Variance Trade-off）：模型过于简单（如用直线拟合弯曲曲线）会导致高偏差（欠拟合），训练集和验证集误差都很高；模型过于复杂则会把训练噪声当规律记住，导致高方差（过拟合），训练误差极低而验证误差反弹。

特征工程与防泄漏评估纪律

在真实数据挖掘项目中，数据清洗质量与评估口径的严谨程度往往比更换算法更能决定上线成败。

特征准备与数据泄漏防范

  • 缺失值处理：先判断缺失本身是否带有业务含义；数值列常用中位数或模型插补，必要时额外增加一列“是否缺失”标记。
  • 缩放与类别编码：线性模型、kkk-NN、SVM 和 PCA 需要先做标准化（零均值、单位方差）；类别字段低基数时常用独热编码（One-Hot），高基数时需在交叉验证折内谨慎做目标编码。
  • 严防数据泄漏（Data Leakage）：切忌在划分训练集与测试集之前，对全量数据一起计算均值、方差、插补值或做特征筛选。 凡是让验证/测试集的统计分布提前渗入训练流程的操作，都会制造虚高的离线指标。

数据切分方式与指标选择

只有当样本彼此独立同分布时，随机切分才成立。两类常见场景必须采用结构化切分：

  • 分组数据（同一用户、同一设备或同一条采集路线有多条记录）：使用 Group KKK-Fold，确保同一实体不会同时出现在训练集和验证集里；
  • 时间序列数据：严格按时间先后切分（用过去训练、用未来验证），禁止用未来信息预测过去。

评估指标同样必须对齐业务成本。在极度不平衡的分类任务中，单纯看准确率（Accuracy）极具误导性：假设 1,000 笔交易中只有 10 笔欺诈（1%），一个把所有交易都判为正常的傻瓜模型也能拿到 99.0% 的准确率，但对欺诈的召回率为 0%（计算值）。若某个真实风控模型共预警 12 笔，其中 8 笔确为欺诈：

  • 精确率（Precision） =812≈66.7%= \frac{8}{12} \approx 66.7\%=128​≈66.7%（计算值）——报出来的警报里有多少是真的；
  • 召回率（Recall） =810=80.0%= \frac{8}{10} = 80.0\%=108​=80.0%（计算值）——所有真实欺诈里抓住了多少；
  • F1 分数 =2×Precision×RecallPrecision+Recall=1622≈72.7%= \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{16}{22} \approx 72.7\%=Precision+Recall2×Precision×Recall​=2216​≈72.7%（计算值）——两者的调和平均。

当模型输出连续概率且阈值待定时，使用 ROC-AUC 与 PR-AUC（在稀有正类场景下优先看 PR-AUC）能比单一阈值准确率更客观地衡量排序能力。
