导航修正的留出验证：共享误差下的候选冻结与预测评分

同一部手机的两批 WiFi 扫描即使相隔数秒，也可能共有设备或地图偏差。在 T31 的留出评分中，我们用前两批扫描固定候选修正，再按各自截止时刻的状态和协方差给两次留出观测评分。给第二项评分时，还要以已经收到的第一项为条件。

假设我们根据一批 WiFi 扫描把轨迹向东修正几米，修正后的位置更符合地图。几秒钟后又收到一批扫描，如果把它们也交给求解器重新选位移，拟合分数很可能继续上升。要判断原来的修正能否用于后续定位，我们得在调整位移之前检验它对这批新扫描的预测。

为此，我们用前两段扫描 A、B 构造候选修正，把第三段 C 留作验证。三段扫描的时间互不重叠，但它们来自同一部手机，定位时又共用惯性轨迹与指纹地图，因此设备的信号强度偏差可能贯穿三个时段。两次高斯观测的算例能说明共享偏差如何改变条件预测。在平层步行日志 T31 中，保存的是状态间的交叉协方差，我们根据它复算两次留出评分，再检查观测模型还作了哪些假设。

共同偏差对分时观测的影响

先只看两个时刻。设真实位置分别为 x1,x2x_1,x_2x1​,x2​，两次位置观测都带有同一个未知偏差 bbb，此外各自还有测量噪声。

z1=x1+b+ϵ1,z2=x2+b+ϵ2.z_1=x_1+b+\epsilon_1,\qquad z_2=x_2+b+\epsilon_2.z1​=x1​+b+ϵ1​,z2​=x2​+b+ϵ2​.

即使 ϵ1\epsilon_1ϵ1​ 和 ϵ2\epsilon_2ϵ2​ 独立，只要共同偏差 bbb 未知，z1z_1z1​ 与 z2z_2z2​ 的误差就仍然相关。把第二个窗口推迟十秒也消除不了同一部设备的 RSS 偏差。两次定位若使用了同一张指纹地图、相同的轨迹初始姿态或重叠的惯性输入，也会共享相应的误差。

在这个线性高斯例子里，我们把两项观测放进同一个向量，保留它们之间的交叉协方差。联合分布可以写成

[z1z2]∼N ⁣([μ1μ2],[S11S12S21S22]).\begin{bmatrix}z_1\\z_2\end{bmatrix} \sim \mathcal N\!\left( \begin{bmatrix}\mu_1\\\mu_2\end{bmatrix}, \begin{bmatrix}S_{11}&S_{12}\\S_{21}&S_{22}\end{bmatrix} \right).[z1​z2​​]∼N([μ1​μ2​​],[S11​S21​​S12​S22​​]).

因此，在已知第一项观测 z1z_1z1​ 时，第二项的条件均值和协方差分别为

μ2∣1=μ2+S21S11−1(z1−μ1),S2∣1=S22−S21S11−1S12.\mu_{2\mid1}=\mu_2+S_{21}S_{11}^{-1}(z_1-\mu_1),\qquad S_{2\mid1}=S_{22}-S_{21}S_{11}^{-1}S_{12}.μ2∣1​=μ2​+S21​S11−1​(z1​−μ1​),S2∣1​=S22​−S21​S11−1​S12​.

计算这两个条件量时，直接解线性方程即可。第一项观测既更新了我们对共同偏差的估计，也减少了它的不确定性，因而第二项观测的预测均值和方差都会改变。如果第二项偏移的方向与第一项一致，这种偏移就更容易由共同偏差解释；如果方向相反，它在条件分布下反而可能更异常。

我们取一组可以手算的数。令共同偏差的方差为 4，两次独立噪声的方差均为 1，扣去已知位置 x1,x2x_1,x_2x1​,x2​ 后，两次观测残差的联合协方差为

S=[5445].S=\begin{bmatrix}5&4\\4&5\end{bmatrix}.S=[54​45​].

例如，第一次测得的残差为 2，第二次的条件均值就从 0 移到 4/5×2=1.64/5\times2=1.64/5×2=1.6，方差也从 5 降为 5−16/5=1.85-16/5=1.85−16/5=1.8。第一项观测提供了有关共同偏差的信息，因此检验第二项时，我们既要以更新后的均值为中心，也要使用缩小后的方差。

用两批扫描构造候选修正，留出第三批验证

图 1　A、B 用于构造候选。流程中的 Freeze 表示在读取 C 前就固定候选和评分规则，三段扫描共有的不确定性仍须保留。此后 C 的作用是检验预测。

我们把维持原轨迹的方案记作 KEEP，用 θ\thetaθ 描述候选修正。它可以是平移、有限旋转，也可以改变某一段的状态约束。A、B、C 标记的是构造和确认各用了哪批数据。其他实验把四份快照称作 A、B、C、D，用的是另一套编号。

先从 A 和 B 分别估计 θ^A\hat\theta_Aθ^A​、θ^B\hat\theta_Bθ^B​，检验两组扫描给出的修正是否相容。通过这一步后，再将两批数据中各自独有的信息与共享的信息纳入同一个模型，得到联合候选。此时才能固定候选，对 C 做一次样本外预测。

两批扫描若各自给出修正 θ^A\hat\theta_Aθ^A​、θ^B\hat\theta_Bθ^B​，我们可以检查它们的差值 d=θ^A−θ^Bd=\hat\theta_A-\hat\theta_Bd=θ^A​−θ^B​。这个差值该容许多大变化，取决于两次估计各自的不确定性，也取决于它们共有多少误差。

Cov⁡(d)=PA+PB−PAB−PABT.\operatorname{Cov}(d)=P_A+P_B-P_{AB}-P_{AB}^{T}.Cov(d)=PA​+PB​−PAB​−PABT​.

若用 PA+PBP_A+P_BPA​+PB​ 作为差值的协方差，就相当于预设交叉项为零。两次估计可能受共同误差影响，同时偏向错误的位置，因此它们彼此接近只能说明相容。忽略交叉项还会误估差值的不确定性，导致相容性检验过松或过严。

联合估计时还要核对先验的来源。如果 A、B 各自的后验都已包含同一份初始先验，再把它们当作独立测量融合，就会把这份信息计算两次。我们可以回到原始因子建立联合模型，也可以使用与之等价的表示，只要其中明确给出条件信息和交叉协方差。

验证前冻结的模型参数与评分规则

在读取 C 前，需要固定候选参数与构造它所用的数据，同时记录状态后验的近似方式、噪声模型、模态权重、NULL 分支、相关组划分、观测绑定、数值积分规则和候选选择策略。如果还要控制反复尝试带来的误报风险，相应的风险预算也要在这一步确定。

在这份 T31 快照里，我们保留 WiFi 原来的三个位置模态及其概率质量，未把它们先平均成一个中心。观测模型取 ν=4\nu=4ν=4 的 Student-t，提供者给出的 QQQ 在这里是尺度矩阵，对应的单模态协方差为 2Q2Q2Q。表示不属于这些位置的 NULL 分支也沿用冻结的权重和密度。不过快照只保存了背景密度在此处的值，足以复算历史分数，要检验整个观测域上的密度是否归一化，还缺其余部分的定义。

这样，后续观测检验的始终是事先给出的同一个预测。噪声模型如果本来就与实际观测不符，固定规则会让这种偏差暴露出来，却无法替代模型校准。

对状态后验积分求预测密度

对第 iii 次观测，冻结的似然形状是

gi(xi)=(1−πi)∑kwik t4(zik−xi;Qi)+πici.g_i(x_i)=(1-\pi_i)\sum_k w_{ik}\, t_4(z_{ik}-x_i;Q_i)+\pi_i c_i.gi​(xi​)=(1−πi​)k∑​wik​t4​(zik​−xi​;Qi​)+πi​ci​.

其中 wikw_{ik}wik​ 表示原始模态的概率质量，πi\pi_iπi​ 是 NULL 权重，cic_ici​ 是背景密度。由于轨迹状态本身也不确定，单把其均值代入似然会漏掉这部分误差；我们需要对联合状态分布积分。

q(C1,C2)=∫g1(x1)g2(x2)N(x;μ,P) dx.q(C_1,C_2)=\int g_1(x_1)g_2(x_2) \mathcal N(x;\mu,P)\,dx.q(C1​,C2​)=∫g1​(x1​)g2​(x2​)N(x;μ,P)dx.

把观测似然写成乘积 g1(x1)g2(x2)g_1(x_1)g_2(x_2)g1​(x1​)g2​(x2​)，意味着给定状态后，两次观测可以按上述形式分解。如果设备偏差同时影响两次扫描，却没有进入状态模型，即使保留了状态间的交叉协方差，观测之间仍可能有未建模的相关性。因此我们可以用数值积分核对这个模型的计算结果，模态权重与 NULL 密度则需要另行校准。

Student-t 可以写成高斯尺度混合。二维观测、ν=4\nu=4ν=4 时，

λ∼Gamma⁡(2,2),e∣λ∼N(0,Q/λ).\lambda\sim\operatorname{Gamma}(2,2),\qquad e\mid\lambda\sim\mathcal N(0,Q/\lambda).λ∼Gamma(2,2),e∣λ∼N(0,Q/λ).

这里 Gamma 分布的第二个参数表示速率。给定各个 λi\lambda_iλi​ 后，积分化为高斯卷积：将对应于各观测的 Qi/λiQ_i/\lambda_iQi​/λi​ 加到联合状态协方差 PPP 的对角块，再在观测位置求多元高斯密度。由于 NULL 分支的密度为常数，只需对其余非 NULL 观测涉及的状态保留相应的边缘分布。这样便可逐个枚举模态组合，省去四维位置空间的网格积分。

历史实现采用自适应 Gauss–Kronrod 积分。为了独立核对这一结果，我们改用广义 Gauss–Laguerre 求积。令 u=2λu=2\lambdau=2λ 后，权重成为 ue−uu e^{-u}ue−u，对应 α=1\alpha=1α=1。我们依次取 16、32、64、128 个节点观察结果是否收敛，历史评分器及其参数保持原样。

按观测截止时间累计条件预测分数

下面用下标标明新信息最迟到达的时刻。系统第一次给 C1 评分，随后才在新的截止点给 C2 评分，因此历史记录累计的是

S2=log⁡qt1(C1)+log⁡qt2(C1,C2)qt2(C1).S_2=\log q_{t_1}(C_1) +\log\frac{q_{t_2}(C_1,C_2)}{q_{t_2}(C_1)}.S2​=logqt1​​(C1​)+logqt2​​(C1​)qt2​​(C1​,C2​)​.

第一项使用 t1t_1t1​ 时已经给出的预测，第二项则在 t2t_2t2​ 的联合预测下计算 C2 的条件密度。如果把第一项替换为 log⁡qt2(C1)\log q_{t_2}(C_1)logqt2​​(C1​)，总和就成了后一截止点的联合对数密度，相当于用后来获得的信息修改了第一次评分。

图 3　沿实际到达顺序计分，和把两项都按后一截止点重算，两种总量相差约 0.146236，差别来自 C1 使用的信息。固定在后一截止点，C2 以 C1 为条件时又比单独使用其边际密度高约 0.540286 个对数单位。

这里没有“分数越负候选越差”这种无条件结论。连续密度带着单位和维度，跨不同的观测空间比绝对对数密度没有意义。要比候选和 KEEP，就要在同一批观测、同一个基本测度、同一份可用信息下分别构造预测分布。表中只重算了候选，缺少同信息条件的 KEEP 评分，因此不能从这六个数判定应接纳修正。

使用似然比进行序贯检验的条件

两种假设 H1,H0H_1,H_0H1​,H0​ 都定义了下一步的合法条件分布时，可以构造

Lt=∏i=1tp1(zi∣Fi−1)p0(zi∣Fi−1).L_t=\prod_{i=1}^{t} \frac{p_1(z_i\mid\mathcal F_{i-1})}{p_0(z_i\mid\mathcal F_{i-1})}.Lt​=i=1∏t​p0​(zi​∣Fi−1​)p1​(zi​∣Fi−1​)​.

当支持集、条件模型和可预测选择均满足相应假设时，简单零假设下有 E0[Lt∣Ft−1]=Lt−1\mathbb E_0[L_t\mid\mathcal F_{t-1}]=L_{t-1}E0​[Lt​∣Ft−1​]=Lt−1​。我们便可以利用非负鞅或超鞅的越界概率来确定停止条件。例如，若下一条消息只是复制上一条，已知上一条后它便没有提供新的随机信息；再乘一次相同的似然比会重复计算证据。

实际导航中的方差由数据估计，候选经过筛选，模态质量也可能依赖经验，背景分布往往只知道一部分。因此，即便程序把分数命名为 log_score，而且这次分数持续改善，我们仍要逐项检查前述假设。若零假设涵盖多个可能的分布，检验还须对规定的整个分布类有效，只在一个拟合出的参考模型上验期望并不足够。

2026 年的 Sequential testing of conditionally constrained hypotheses 研究了由有限个条件约束描述的假设类，以及可预测的一步 e-variable 乘积。要沿用论文的越界概率保证，每一步都须满足规定的条件约束。T31 的评分还缺少零假设下的校准，因此不能直接用这些定理标定误报率。1

两次留出扫描足以核对条件积分与冻结评分之间的数值关系。要报告在线阈值的误报率，还需要在相同条件下补全维持原轨迹（KEEP）的对照与风险标定。

为了让别人能够复查每笔分数，我们为它保留模型版本、可用信息截止点和观测来源。积分尚未收敛时先将这笔结果记为“未解析”。若发现共同先验重复计入，就需要重建联合模型。若已经看过 C 再调整候选，则要另选验证数据，因为原来的 C 已经参加了构造。

因此，实施 A/B/C 留出验证时，应在看到 C 之前保存候选对它的预测以及当时的可用信息。等 C 到达后，我们才能直接检验这次预测，并把结果与重新拟合 C 所取得的分数区分开。
