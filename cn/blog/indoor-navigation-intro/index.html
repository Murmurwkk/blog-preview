室内导航算法入门：步行推算、SE(2) 几何、WiFi 指纹与位姿图

室外导航可以依赖卫星定位（GNSS/GPS）直接读取绝对坐标，但进入室内、地下通道或高楼密集区后，卫星信号会被建筑遮挡或严重反射。因此，室内导航算法天然是一个跨领域协作的系统，需要把机器人 SLAM 里的刚体几何、无线信号的统计指纹模型、控制理论中的递推滤波以及数值优化里的图优化组合起来。这篇导读按认知顺序介绍这些基础组件：步行推算与 SE(2)SE(2)SE(2) 平面位姿、RSSI 信号指纹与 WKNN、卡尔曼滤波融合，以及位姿图与鲁棒估计的入门概念。

核心矛盾：短期准的相对推算与长期稳的绝对观测

几乎所有定位算法都在调和两类互补的线索：

  • 相对推算（Dead Reckoning）：依靠惯性传感器（IMU）、轮速计或步频/航向估计，追踪“相比上一秒我往前走了几米、转了多少度”。它在几秒内平滑且精确，但每一步的微小误差都会不断累积，导致轨迹越走越偏（漂移 / Drift）。
  • 绝对观测（Absolute Clues）：依靠 WiFi、蓝牙、UWB、气压计、视觉地标或磁场特征，把当前状态拉回已知地图坐标系。单次读数往往噪点很大，有时还会出现多个相似位置，但它的误差不会随行走时间无限增长。
flowchart LR
    M[相对运动：IMU / 步长 / 里程计<br/>短期平滑，长期持续漂移] --> F[多传感器融合估计器<br/>卡尔曼滤波 或 位姿图优化]
    A[绝对线索：WiFi RSSI / 地标 / 气压计<br/>单次噪点大，长期误差有界] --> F
    F --> T[输出连续轨迹与不确定度]

平面几何与 SE(2)：为什么位姿不能当作普通向量

人在楼层平面上的状态由位置 (x,y)(x, y)(x,y) 和朝向角 θ\thetaθ 构成。如果直接把 (x,y,θ)(x, y, \theta)(x,y,θ) 当作普通三维向量做加减，会立刻遇到两个错误。

第一，角度定义在圆周上而非直线上：从 359∘359^\circ359∘ 左转 2∘2^\circ2∘ 得到的是 1∘1^\circ1∘ 而不是 361∘361^\circ361∘；359∘359^\circ359∘ 与 1∘1^\circ1∘ 的真实夹角是 2∘2^\circ2∘ 而不是 358∘358^\circ358∘。第二，平移和旋转不满足交换律。假设一个人站在原点 (0,0)(0, 0)(0,0) 面向正东（θ=0∘\theta = 0^\circθ=0∘）：

  • 先向前走 2 米，再左转 90∘90^\circ90∘：终点位于 (2,0)(2, 0)(2,0)，面朝正北（θ=90∘\theta = 90^\circθ=90∘）；
  • 先左转 90∘90^\circ90∘，再向前走 2 米：终点位于 (0,2)(0, 2)(0,2)，同样面朝正北（θ=90∘\theta = 90^\circθ=90∘）。

两次运动的最终朝向相同，落点却完全不同。为此，机器人学与 SLAM 使用平面特殊欧氏群 SE(2)SE(2)SE(2) 表示二维刚体位姿，写成 3×33 \times 33×3 齐次变换矩阵：

T=(cos⁡θ−sin⁡θxsin⁡θcos⁡θy001)T = \begin{pmatrix} \cos\theta & -\sin\theta & x \\ \sin\theta & \cos\theta & y \\ 0 & 0 & 1 \end{pmatrix}T=​cosθsinθ0​−sinθcosθ0​xy1​​

将局部相对运动 ΔT\Delta TΔT 叠加到当前位姿 TkT_kTk​ 上，只需做矩阵乘法 Tk+1=TkΔTT_{k+1} = T_k \Delta TTk+1​=Tk​ΔT，当前朝向 θk\theta_kθk​ 会自动把局部步长旋转到全局坐标系中。

这种旋转与平移的耦合也解释了为什么航向误差是漂移的头号来源：如果航向存在 5∘5^\circ5∘ 的常值偏差，即使每一步的步长测得丝毫不差，沿直线走完 50 米后横向偏移也会达到 50sin⁡5∘≈4.36 米50 \sin 5^\circ \approx 4.36\text{ 米}50sin5∘≈4.36 米（计算值）。

无线信号指纹：RSSI 与 WKNN

为了抑制漂移，室内系统常采集周围 WiFi 接入点（AP）的接收信号强度（RSSI），单位为 dBm（数值越接近 0 信号越强，例如 −45 dBm-45\text{ dBm}−45 dBm 明显强于 −85 dBm-85\text{ dBm}−85 dBm）。

室内墙壁、玻璃、家具和走动的人群会引起强烈的反射与遮挡（多径效应），直接按自由空间衰减公式把 RSSI 换算成物理距离往往误差极大。工程上更常用指纹定位（Fingerprinting）：先在离线阶段采集已知坐标点的多 AP 信号向量建成指纹地图，在线阶段再把实时扫描向量与地图比对。

最基础的匹配方法是加权 kkk 近邻（WKNN）。假设实时扫描到两个 AP 的强度为 z=(−55,−70) dBmz = (-55, -70)\text{ dBm}z=(−55,−70) dBm，地图上有两个参考点：

  • 参考点 AAA 位于 (0,0) m(0, 0)\text{ m}(0,0) m，指纹为 (−52,−66) dBm(-52, -66)\text{ dBm}(−52,−66) dBm：信号空间欧氏距离 dA=(−55+52)2+(−70+66)2=9+16=5 dBd_A = \sqrt{(-55+52)^2 + (-70+66)^2} = \sqrt{9+16} = 5\text{ dB}dA​=(−55+52)2+(−70+66)2​=9+16​=5 dB（计算值）。
  • 参考点 BBB 位于 (10,0) m(10, 0)\text{ m}(10,0) m，指纹为 (−63,−76) dBm(-63, -76)\text{ dBm}(−63,−76) dBm：信号空间欧氏距离 dB=(−55+63)2+(−70+76)2=64+36=10 dBd_B = \sqrt{(-55+63)^2 + (-70+76)^2} = \sqrt{64+36} = 10\text{ dB}dB​=(−55+63)2+(−70+76)2​=64+36​=10 dB（计算值）。

按距离倒数赋权 wi=1/diw_i = 1 / d_iwi​=1/di​，得到 wA=0.2w_A = 0.2wA​=0.2、wB=0.1w_B = 0.1wB​=0.1，归一化后权重分别为 w~A=2/3\tilde{w}_A = 2/3w~A​=2/3 和 w~B=1/3\tilde{w}_B = 1/3w~B​=1/3（计算值）。由此算出 WKNN 估计位置：

x^=23(0)+13(10)≈3.33 m,y^=0 m（计算值）\hat{x} = \frac{2}{3}(0) + \frac{1}{3}(10) \approx 3.33\text{ m}, \qquad \hat{y} = 0\text{ m} \quad \text{（计算值）}x^=32​(0)+31​(10)≈3.33 m,y^​=0 m（计算值）

WKNN 实现直观、不需要预设传播公式，但归一化权重不能直接等同于定位置信度。如果隔着承重墙的两条对称走廊恰好给出相同的信号距离（dA=dBd_A = d_BdA​=dB​），WKNN 会对两个候选位置取平均，把结果算进中间的实心墙里。概率指纹模型（如每个位置的信号分布模型或空间高斯过程 GP 场）通过同时建模期望信号与方差，为后续融合提供更有意义的统计不确定度。

传感器融合：递推滤波与位姿图优化

拿到相对运动与绝对观测后，主流融合方法分为两大流派。

递推滤波（卡尔曼滤波直觉）

卡尔曼滤波（Kalman Filter）只维护当前时刻的状态估计（均值 x^\hat{x}x^ 与协方差 PPP），按两步循环推进：

  1. 预测（Predict）：用相对运动把状态往前推一步；由于运动有噪声，不确定度 PPP 随之变大。
  2. 更新（Update）：收到绝对观测后，按两者各自的不确定度计算最优权重（卡尔曼增益 KKK），把预测值向更可信的观测值拉近。

用一维数值举例：步行推算预测当前位置为 x^−=10.0 m\hat{x}^- = 10.0\text{ m}x^−=10.0 m，方差 P−=4.0 m2P^- = 4.0\text{ m}^2P−=4.0 m2（标准差 2.0 m2.0\text{ m}2.0 m）；WiFi 观测给出 z=13.0 mz = 13.0\text{ m}z=13.0 m，方差 R=1.0 m2R = 1.0\text{ m}^2R=1.0 m2（标准差 1.0 m1.0\text{ m}1.0 m）。此时卡尔曼增益为：

K=P−P−+R=4.04.0+1.0=0.8（计算值）K = \frac{P^-}{P^- + R} = \frac{4.0}{4.0 + 1.0} = 0.8 \quad \text{（计算值）}K=P−+RP−​=4.0+1.04.0​=0.8（计算值）

融合后的位置更偏向精度更高的 WiFi 观测，且融合方差比任意单个传感器都更小：

x^+=10.0+0.8×(13.0−10.0)=12.4 m,P+=(1−0.8)×4.0=0.8 m2 (σ≈0.89 m)（计算值）\hat{x}^+ = 10.0 + 0.8 \times (13.0 - 10.0) = 12.4\text{ m}, \qquad P^+ = (1 - 0.8)\times 4.0 = 0.8\text{ m}^2 \ (\sigma \approx 0.89\text{ m}) \quad \text{（计算值）}x^+=10.0+0.8×(13.0−10.0)=12.4 m,P+=(1−0.8)×4.0=0.8 m2 (σ≈0.89 m)（计算值）

由于二维和三维旋转是非线性的，实际系统常使用在当前估计点做局部线性化的扩展卡尔曼滤波（EKF），或用一组带权假设同时追踪多个候选走廊的粒子滤波（Particle Filter）。

位姿图与因子图优化

递推滤波每次只修正当前状态，历史状态一旦边缘化丢弃，后续看到新地标或回到旧地点时就无法回头拉直整段历史轨迹。

因子图（Factor Graph / 位姿图）把一段轨迹上的所有位姿 {T0,T1,…,Tn}\{T_0, T_1, \dots, T_n\}{T0​,T1​,…,Tn​} 保留为节点，把每条传感器测量建成连接节点的因子（可以想象成不同劲度系数的弹簧）：里程计因子连接相邻位姿 (Tk,Tk+1)(T_k, T_{k+1})(Tk​,Tk+1​)，WiFi 或地标因子锚定单个位姿，当用户回到曾经经过的区域时，回环因子（Loop Closure）把相隔很远的两个节点重新拉近。

求解位姿图就是寻找一组位姿，使所有因子的加权残差平方和最小：

由于 SE(2)SE(2)SE(2) 运动约束是非线性的，求解器在当前轨迹附近反复线性化，借助高斯–牛顿法（Gauss–Newton）或莱文伯格–马夸特法（LM）迭代逼近最优解，并利用图的稀疏结构保持实时计算速度。

真实室内数据里的三个经典陷阱

课本里的理想假设通常是高斯白噪声与独立同分布样本，而真实采集的数据经常打破这些前提：

  • 重尾异常值（Outliers）：一次偶然的穿墙信号、误判楼层或手机放进口袋引起的抖动，会产生极大的测量残差。标准平方误差会按平方放大异常值的影响，把整段轨迹扯偏；工程实现通常改用 Huber、Cauchy 或 Student-ttt 等鲁棒损失函数，压低极端残差的拉扯力。
  • 不可观性与标定问题：仅凭相对运动无法自行确定初始绝对朝向，某些传感器常值偏置（如磁力计硬铁偏移）若没有足够转弯激励或外部锚点就无法从数据中唯一辨识。
  • 评估中的数据泄漏：把同一条行走轨迹随机切分为训练集和测试集时，相邻一秒的扫描几乎一模一样，测出的误差会严重虚低。可靠的室内定位评估应按整条独立路线或独立楼层/建筑留出来检验泛化能力。
