语言模型的机制可解释性：从归纳头到稀疏特征与归因图

稀疏字典可以找出模型中反复响应某类输入的特征。即使用 TopK 或 JumpReLU 训出能命名的特征，仍要检验它是否参与了一次具体预测：Claude 的加法案例说明，模型口述的解题步骤与归因图中追踪到的计算可能不同。

研究人员问 Claude 3.5 Haiku，36 加 59 怎样计算。模型答出 95，并解释说先把个位相加，再向十位进位。不过，在用于追踪这次回答的替代模型里，研究人员找到了两条并行的路径：一条估计总和的大致范围，另一条确定末位数字，两条路径的结果再结合起来。对同一个正确答案，模型的口头说明和研究者实际追踪到的计算给出了不同的解释。

另一个实验为 Claude 3 Sonnet 的激活学出了一本约有 3,400 万个特征方向的词典。研究者从中辨认出了能用自然语言描述的特征。把其中一个特征固定在很高的激活值，模型会在许多不相关的回答中提到相应话题。两个实验都考察模型的内部表示，却回答不同的问题。找到一个能读懂、甚至能操纵的方向，怎样进一步证明模型本来就在用它生成某个答案？

这一区别也是机制可解释性（mechanistic interpretability）研究逐步转向特征和电路的原因。早期研究先从权重中追踪计算路径。发现单个神经元可能同时响应多个概念后，研究者开始用稀疏自编码器（sparse autoencoder，SAE）学出一套特征词典。有了字典，仍需回到具体的计算路径，检验哪些特征实际影响了某一次预测。下文的案例均来自文末所列论文，代码摘自 SAELens 与 TransformerLens。

残差流中的信息传递与归纳头电路

Transformer 的每个块都把输出加到残差流（residual stream）上，以后的块从这份累加结果中取输入。《A Mathematical Framework for Transformer Circuits》从这条架构事实入手，把模型输出拆成许多计算路径的贡献：词嵌入直接到输出、嵌入先过一个注意力头、再串过两个头，等等。

    R1 --> H1["第一层的注意力头"]
    H1 -- "加上输出" --> R2(("残差流"))
    R1 --> R2
    R2 --> H2["第二层的注意力头"]
    H2 -- "加上输出" --> R3(("残差流"))
    R2 --> R3
    R3 --> U["下一个词元的 logits"]

图 2　纵向箭头表示残差流将已累加的信息传给后层。侧面的注意力头先读取残差流，再把结果写回；顺着这些箭头，就能追踪前一层的输出怎样参与后续计算。

沿着残差流分析一个注意力头时，可以分别考察它从哪里读取信息、向后传递哪些信息。QK 电路 WQ⊤WKW_Q^\top W_KWQ⊤​WK​ 决定当前位置对哪些早先的位置分配较高的注意力权重；OV 电路 WOWVW_O W_VWO​WV​ 决定从这些位置读取哪些信息，并将结果写入残差流的哪些方向。如果一条经过这些矩阵的路径能实现可观察行为，就有了一个值得验证的电路。原文对零层、一层和两层的纯注意力模型能精确推导，模型扩大到七十层，怎样找到要追的路径却仍是难题。

归纳头（induction head）给出了具体例子。假设上下文先出现过 A B，后来又遇到 A。模型若能找到上一次 A 后面的位置，就能把 B 提到预测前列。第一个注意力头负责记录前一个词元，因此历史位置上除了当前词元，还携带了前一个词元的信息。第二个头利用这条记录，寻找前面同样是 A 的历史位置，再提高该位置词元的预测分数。研究者用六类证据检验这两个头的配合。例如在训练过程中，归纳头出现的时间与上下文学习能力跃升的时间十分接近；当研究者移除这些头，相应的能力也随之减弱。

五个稀疏特征在二维空间中的叠加

归纳头给出了可辨认的计算路径，但其中的特征是否一定对应单个神经元，还需另行检验。《Toy Models of Superposition》为此构造了一个小模型：把 nnn 个输入特征压进 m<nm<nm<n 个隐维度，再重构出来，输出带 ReLU。若各种特征大多同时出现，模型宁可给最重要的几个特征各留一根轴，放弃其余特征。若每次只激活很少的特征，两条不正交的方向也很少碰撞，于是同一个二维空间可以容下比两种更多的特征。这就是叠加（superposition）。

图 3　左图中多个特征经常同时出现，两个坐标轴不足以将它们分别编码。右图中的特征很少同时出现，因此可以用五边形的五个方向表示。两图都是机制示意；改变特征的重要性，还可能学出对径点或三角形排列。

既然一个特征方向可以分布在多个神经元上，我们可以直接寻找一组方向，使少数方向的线性组合足以还原一次激活。这正是字典学习要解的问题。

用稀疏字典识别和检验潜在特征

《Towards Monosemanticity》在一个单层 Transformer 上取含 512 个神经元的 MLP 激活，训练宽度从 512 到 131,072 的稀疏字典；主要分析用 4,096 个潜特征（latent），是输入维度的八倍。研究者给特征看高激活文本、看它如何影响输出 logits，也尝试把它去掉。许多方向可以取一个相当稳定的名字；换更宽的字典，原来一个粗特征还会拆出更细的方向。

《Scaling Monosemanticity》将同一套字典学习方法用于 Claude 3 Sonnet，分别学习约 100 万、400 万和 3,400 万个特征。部分方向跨语言激活，有些对图像与文本都有反应，还有与安全行为相关的方向。固定某个特征的值，往往会让回答朝可解释的方向变化。这个实验说明，改变该方向能影响生成。要回答“模型在正常状态下这一次是否经由它完成计算”，还得从实际输出往回追。后文的归因图正为此而来。

TopK 限制单个样本最多有 kkk 个非零系数。 这是因为 SAELens 按下面的顺序进行筛选：

topk_values, topk_indices = torch.topk(x, k=self.k, dim=-1, sorted=False)
values = topk_values.relu()
result = torch.zeros_like(x)
result.scatter_(-1, topk_indices, values)

第一行按大小挑 kkk 个预激活，第二行才去掉负值。如果一个词元只有三个值为正，k=8k=8k=8 也只能留下三项非零。scatter_ 把留下的数放回它们原来的特征编号。BatchTopK 进一步把限额挪到整批，在一批里挑最大的 k×batch sizek\times\text{batch size}k×batch size 个，简单的词元可以少用，复杂的多用。

前一个近似比后一个多乘一个 θ\thetaθ。原因是 JumpReLU 跨过阈值时，输出会从零跃至预激活值，而 Step 只记录该特征是否激活。特征保留时，输出对输入 uuu 的梯度可以直接传回。SAELens 的 JumpReLU 和 Step 两个自定义 torch.autograd.Function 分别实现了这两条近似。

图 5　虚线把一次参数更新连接到下一批训练数据。训练结束后，才将重构的激活放回原模型，检查交叉熵，同时统计非零特征数并评价解释质量。训练损失本身无法替代这些检验。

  1. 采集激活。 首先在一大批语料上运行模型，用钩子（hook）捕捉残差流、MLP 输出或注意力输出，缓存后打乱。各批激活的范数若不断变化，词典有可能学会跟随尺度。SAELens 可选 none、expected_average_only_in、constant_norm_rescale、layer_norm 和 covariance_whitening。
  2. 初始化。 在 SAELens v6.20.0 中，训练配置 TrainingSAEConfig.decoder_init_norm 默认为 0.1。初始化时，每个解码特征向量先缩放到这个范数，再将解码器权重转置并复制给编码器，解码器偏置从零开始。训练时也要留意尺度。如果直接用系数的 L1 范数作为惩罚，把系数缩小、对应的解码向量按反比例放大，就能在重构不变的情况下降低惩罚。训练配置 · 权重初始化
  3. 优化。 常用 Adam、学习率预热和衰减。批量用词元数计，因为每个词元都贡献一个激活向量。TopK 论文训练 GPT-4 的 SAE 时使用了 400 亿个词元。
  4. 处理死特征。 一个潜在方向如果长期没有激活，就会占用字典容量，并影响对实际稀疏程度的判断。阈值按前向经过的步数计算，见下方的计数器。TopK 的 AuxK 让排名靠前的休眠特征去重构当前残差，以此获得梯度。JumpReLU 一类做法用预激活损失将死特征推回阈值附近。较早的 L1 配方还会用那些重构很差的输入重新初始化死特征。
  5. 评价。 前一篇的玩具实验里，允许更多方向激活，重构虽更好，找回真实生成方向的数量反倒减少。常用评价同时看插回原模型后的下一词元交叉熵恢复程度、每词元激活数 L0、死特征比例、自动解释质量、稀疏探针和因果干预。自动解释让模型根据高激活样本给特征命名，再评价名称。SAEBench 在几百个公开 SAE 上并列这些指标，让单项成绩的代价显现出来。
def dead_neurons(self) -> torch.Tensor:
    return (self.n_forward_passes_since_fired > self.cfg.dead_feature_window).bool()

TransformerLens 在需要读取或替换激活的位置放置一个名为 HookPoint 的恒等模块。默认情况下它直接返回输入，因此注册钩子之前不会改变前向计算。

def forward(self, x: Tensor) -> Tensor:
    return x

注册函数可以保存经过的 x，也能在推理时返回另一个向量。SAELens 的 HookedSAETransformer.add_sae(sae) 把 SAE 接到指定名称上，还能把重构误差单独保留。这样研究者可以查看重构贡献，同时让原模型继续收到完整激活，即使 SAE 还原得有误差。

钩子名称还确定了字典究竟用哪一处激活训练，因此属于实验条件的一部分。blocks.5.hook_resid_pre 读索引为 5 的块的入口；blocks.5.hook_attn_out 读该块注意力准备写回的增量。它们可有完全一样的张量形状，学到的词典却回答两个不同问题。

从激活特征追踪单次预测的计算路径

Claude 归因图中的替代模型与干预检验

《On the Biology of a Large Language Model》为 Claude 3.5 Haiku 构造替代模型，再对给定提示的目标输出画归因图（attribution graph）。要用这张图解释一次预测，先要弄清哪些 MLP 被替换、原模型的哪些量被保留，以及替代模型的误差在哪里呈现。

  • 用跨层转码器替代 MLP。 约 3,000 万个特征中的每一个，可以从某层残差流读取，又写到该层和后续层的 MLP 输出。普通自编码器从激活重构原激活；转码器（transcoder）从 MLP 输入预测其输出，因而能追踪一个特征从哪一层读入，又通过哪些 MLP 输出影响后续层。
  • 固定给定提示下的注意力与归一化。 研究者沿用原模型处理该提示时的注意力模式与归一化分母。特征仍需经过 JumpReLU，整个替代模型仍有非线性；在这些量固定后，一个已激活特征经由残差流和注意力，直接影响后续特征预激活的那一段可以线性计算。
  • 用误差节点保留未重构的贡献。 如果替代模型在某个位置没能重构原模型的输出，归因图可以用单独的节点记录差值。这样，即使一项贡献尚无法解释，读图时仍能看到它来自哪个位置。

    F1 -- "冻结的注意力在词元位置之间搬运信息" --> F2["较晚层的特征"]
    F2 --> O["目标词元的输出 logit"]

图 6　在固定注意力与归一化后，可以沿目标 logit 精确回算图中各个直接作用。示意图省略了与特征并列的误差节点；完整追踪会把它们一起保留。

这就解释了开头的加法案例：在这次输入的替代计算里，估计总和的大致范围和确定个位数是两条并行路径。研究者也在写诗的例子中观察到，模型在完成整行之前就选定了行尾的押韵词。在另一个产生幻觉的例子里，识别实体的信号抑制了原本活跃的“无法回答”特征，使模型即使缺少相关知识，仍会给出一个答案。

这些路径都对应特定提示产生的一次输出。更换提示后需要重新计算归因；而图中的误差节点只是标出替代模型未能解释的贡献，并未揭示其内部机制。训练转码器本身也有成本。图最有说服力之处，是能指出哪条可检验的路径与模型的口头说明不一致。

跨编码器对跨层和跨模型特征的对齐

跨编码器（crosscoder）让多层甚至多个模型共用一个字典。如果某个方向在连续几层的残差流中一直保留，逐层训练的 SAE 只能分别描述该方向在每层的表现。共用字典则使研究者有机会识别同一个跨层特征。对微调前后的模型也可以这样查，哪些方向是后来新增、变弱或消失的。2024 年的相关工作明确是初步探索，仍需验证提取出的跨层方向究竟代表什么。

从模型激活读出自然语言解释

除了沿归因图追踪计算路径，研究者也尝试把模型激活中的信息转换为自然语言。下面三种实验分别检验模型能否报告被注入的概念、文字解释能否重构激活，以及内部表征能否映射为词元。

内省实验把一个概念直接注入模型激活，再问模型是否察觉。《Emergent Introspective Awareness》观察到模型有时能报出注入的概念，有时还会按请求调节内部状态。能否做到高度依赖任务，尚不足以假定模型总能如实报告自己的计算。

自然语言自编码器（NLA）用重构误差来评价文字解释。第一个语言模型将激活写成文字，第二个模型只能依据这段文字重建激活。两个模型都从目标模型初始化，再通过强化学习联合训练。第二个模型还原得越准确，第一个模型给出的解释获得的奖励就越高。

    V --> T["自然语言解释"]

图 7　重构模型只能读取解释文本，不能直接读取原始激活。因此可以把解释中的具体内容，同根据这段文字还原出的激活进行对照。

训练没有另给一份人工“正确解释”，但重构改善时，文本往往也更有信息。在 Claude Opus 4.6 的部署前审计中，NLA 从激活读出模型意识到自己正在接受评估，而原回答未说出这一点。在自动化审计基准上，配有 NLA 的智能体也优于相应基线。代价是要对两个完整语言模型进行强化学习；解释可能编造具体细节，解说者还可能凭自己的推理补足激活里并不存在的信息。

雅可比透镜（Jacobian lens，J-lens）则试图定位模型快要说出口的表征。《Verbalizable Representations Form a Global Workspace》发现这片 J-space 集中在中间若干层，容量有限，大部分特征落在它之外。在论文的干预中，消融最主要的方向会伤害多跳推理，对分类等任务的影响较小。研究还在模型没有公开说出来时从中读到了策略相关内容。另一项训练让模型假设“若被打断，此刻会怎样陈述自己的原则”；经过这种反事实反思训练，不打断它，行为也有所改善。再消融训练植入的相关表征，改善就大半消失。这些结果把可言说的子空间与可定向调节、跨步推理联系了起来。

J++ 的分簇雅可比与读出词元筛选

早期 J-lens 在某一层把大量词元位置上的雅可比矩阵取平均，得到该层一个线性映射，用于从中间激活读出概念。2026 年 10 月的 J++ 更新先给该层的激活聚类，分别拟合每个簇的雅可比，再学得组合权重，把不可靠的簇压到很小。同时引入 R-lens 的逐层相关性传播，过滤虚假的读出词元。最后仍然是每层一个线性映射，可以替换之前的透镜。初步实验在中间变量上的读出更可靠，结果的适用范围仍以这次更新为限。

特征吸收、因果忠实性与大规模分析成本

  1. 特征吸收。 例如，一个专门响应某个词的潜特征可能同时表示这个词的首字母。模型处理该词时，专门表示该首字母的通用潜特征就可能不激活，但词特征已经承担了这部分表示，重构误差仍可以很小。Matryoshka SAE 同时训练从小到大的嵌套字典，尝试显露不同粒度的结构。
  2. 评价指标的取舍。 减弱稀疏约束往往能改善重构，却会让更多特征同时激活。给特征起了更贴切的名字，也无法据此推断移除它会产生多大影响。因而需要分别评价重构误差、L0、死特征比例、自动解释和消融后的变化。
  3. 解释的忠实性。 归因图提供计算假设，文字给出表征假设。开头 36 加 59 的案例已经说明，模型给出的文字解释可能和研究者在替代模型中追踪到的计算路径不同。
  4. 归因计算的规模。 仅保存 3,400 万个方向就要占用大量存储。如果还要为生产模型的每一层、每个位置计算归因图，额外的资源需求就会限制能够逐例追踪的提示数量。
  5. SAE 特征在行为归因中的作用。 转码器可以直接追踪电路，NLA 也能从激活生成解释，不必预先建立 SAE 字典。我认为 SAE 的价值在于为不同研究者提供一套可共同辨认的特征。至于某个特征是否参与了一次具体决策，仍需沿归因图追踪，并用干预检验。
